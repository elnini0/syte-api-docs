The Syte MCP server will let AI assistants that support the Model Context Protocol, such as Claude and ChatGPT, work with your Syte account and catalog in plain language. The first version is read-only.

## Use these docs from your AI tool today

You don't have to wait to use these docs with an AI assistant. The menu next to **Copy page** at the top of every page opens the page in Claude, ChatGPT or Cursor, or connects the whole site to your tool as an MCP server.

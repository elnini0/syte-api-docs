The Syte API powers product discovery on your site: finding products from an image, similar items and Shop the Look, personalized recommendations, text search, collections and galleries. Event tracking measures how shoppers use all of it.

## Before you start

You need two things from Syte:

- Your **account ID**, a number
- Your **API key**

Your Syte account manager sends both when your account is set up.

## Hosts

| Host | Use it for |
| --- | --- |
| `https://syteapi.com` | All endpoints |
| `https://cdn-api.syteapi.com` | CDN-cached host for calls made from the browser. It does not serve event tracking. |

---
title: "Authentication"
description: "API keys, account IDs and the errors you get when either is wrong."
---

Every request needs your API key and your account ID.

## API key

How you pass the key depends on the endpoint.

| Endpoints | Pass the key as |
| --- | --- |
| Visual search, similar items, personalized recommendations, text search, event tracking | `x-api-key` header, or `api_key` query parameter |
| Recently viewed, collections, galleries, widgets | `syte-api-key` header only |

If you send both `x-api-key` and `api_key`, the header wins.

<Warning>
  Recently viewed, collections, galleries and widgets do not accept `x-api-key` or `api_key`. Use the `syte-api-key` header for those.
</Warning>

## Account ID

Your account ID is a number. Where it goes also depends on the endpoint.

| Endpoints | Where | Example |
| --- | --- | --- |
| Visual search, similar items, personalized recommendations, event tracking | `account_id` query parameter | `/v1.1/similars?account_id=12345` |
| Text search, autocomplete, popular searches | Path | `/search/12345/items` |
| Recently viewed, collections, galleries, widgets | Path | `/12345/v2/recently-viewed` |

## Errors

Most endpoints check the account ID and key before anything else.

| Status | Meaning |
| --- | --- |
| `400` | Account ID missing or not a number, API key missing, or the JSON body is invalid |
| `401` | The API key doesn't match the account |
| `403` | The account is blocked, isn't configured yet, or access is denied from your region |

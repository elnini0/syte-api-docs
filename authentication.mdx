---
title: "Authentication"
description: "API keys, account IDs and the errors you get when either is wrong."
---

Every request needs your API key and your account ID.

## API key

How you pass the key depends on the endpoint.

| Endpoints | Pass the key as |
| --- | --- |
| Visual search, similar items, personalized recommendations, event tracking | `x-api-key` header, or `api_key` query parameter |
| Text search, autocomplete, popular searches | `sig` query parameter only |
| Recently viewed, collections, galleries, widgets | `syte-api-key` header only |

If you send both `x-api-key` and `api_key`, the header wins.

<Warning>
  Text search, autocomplete and popular searches reject `x-api-key` and `api_key` with a `403`. Pass the key as `sig` in the query string. Recently viewed, collections, galleries and widgets need the `syte-api-key` header.
</Warning>

## Account ID

Your account ID is a number. Where it goes also depends on the endpoint.

| Endpoints | Where | Example |
| --- | --- | --- |
| Visual search, similar items, personalized recommendations, event tracking | `account_id` query parameter | `/v1.1/similars?account_id=12345` |
| Text search, autocomplete, popular searches | Path | `/search/12345/items` |
| Recently viewed, collections, galleries, widgets | Path | `/12345/v2/recently-viewed` |

## Errors

Most endpoints check the account ID and key before anything else. Errors come back as JSON:

```json
{
  "error": {
    "message": "API key is not provided",
    "code": 400
  }
}
```

| Status | Meaning |
| --- | --- |
| `400` | The API key is missing, the account ID isn't a number, or the JSON body is invalid |
| `401` | The API key isn't valid for this account |
| `403` | The account ID is missing, the account is blocked or not configured yet, or access is denied from your region. A missing account ID returns an HTML error page, not JSON. |

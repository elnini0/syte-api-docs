---
title: "Visual search"
description: "Find products in an image, then get matching products from your catalog."
---

Visual search takes two calls. The first detects the products in an image. The second gets matching products for one of them.

<Steps>
  <Step title="Detect products in the image">
    Send the image URL, URL-encoded, as `imageUrl`. On a product page, also send the product's `sku` and `syte_product=discovery_button`. For a shopper's own photo, use `syte_product=camera`.

    ```bash
    curl "https://cdn-api.syteapi.com/v1.1/offers/bb?account_id=YOUR_ACCOUNT_ID&imageUrl=https%3A%2F%2Fshop.example.com%2Fimages%2Fabc124.jpg&sku=ABC124&syte_product=discovery_button" \
      -H "x-api-key: YOUR_API_KEY"
    ```

    The response has one entry per detected item, with its category, its position in the image and an `offers` link:

    ```json
    {
      "https://shop.example.com/images/abc124.jpg": [
        {
          "label": "Shirts",
          "gender": "female",
          "catalog": "fashion",
          "center": [0.49, 0.33],
          "b0": [0.34, 0.19],
          "b1": [0.64, 0.48],
          "offers": "https://cdn-api.syteapi.com/v1.1/offers?image_url=...&crop=...&cats=...&account_id=YOUR_ACCOUNT_ID&sig=YOUR_API_KEY"
        }
      ]
    }
    ```

    `b0` is the top-left corner and `b1` the bottom-right corner of the item, as fractions of the image width and height.

    <Warning>
      Don't send `fields` on this call. It fails with `422 malformed url list`.
    </Warning>
  </Step>
  <Step title="Get matching products">
    Call the `offers` link as it is, and add `fields` for the product data you want and `size` for how many results.

    ```bash
    curl "OFFERS_LINK&fields=sku,price,imageUrl,offer,brand&size=12"
    ```

    The matches come back in `ads`, most similar first:

    ```json
    {
      "total": 100,
      "currency_tla": "EUR",
      "currency_symbol": "€",
      "ads": [
        {
          "sku": "ABC124",
          "price": "€19.99",
          "imageUrl": "https://shop.example.com/images/abc124.jpg",
          "offer": "https://shop.example.com/p/abc124.html",
          "brand": "Example Brand"
        }
      ]
    }
    ```

    Fetch results for the first detected item straight away, and let the shopper switch to the other items.
  </Step>
</Steps>

<Note>
  `limit` has no effect on the offers call. Use `size`.
</Note>
